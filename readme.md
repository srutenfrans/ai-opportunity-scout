# AI Opportunity Scout

Dit is een interactieve applicatie om ERP-processen en AI-kansen in kaart te brengen, gebouwd met Python en Streamlit.

## Vereisten

*   Python geïnstalleerd (versie 3.8 of hoger).

## Installatie

1.  Open je terminal (Command Prompt of PowerShell).
2.  Navigeer naar de map van dit project:
    ```bash
    cd c:\Users\timte\Desktop\ai-opportunity-scout\
    ```
3.  Installeer de benodigde bibliotheken:
    ```bash
    pip install streamlit pandas plotly
    ```

## De Applicatie Starten

Je kunt de server starten met een van de volgende commando's:

**Optie 1 (Standaard):**
```bash
streamlit run scrippy.py
```

**Optie 2 (Als 'streamlit' niet wordt herkend):**
```bash
python -m streamlit run scrippy.py
```

De applicatie opent automatisch in je webbrowser (meestal op `http://localhost:8501`).
